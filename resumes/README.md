# 📄 CareerOS - Multi-Role Resume Repository

Drop your specialized resume PDFs here! CareerOS features an **Intelligent Resume Selector** that automatically analyzes the job title and description of each position and uploads the most relevant, tailored resume version.

---

## 🏷️ Recommended Naming Conventions

CareerOS automatically categorizes and matches files based on the keywords in their filename:

| Target Role | Recommended Filename Tags | Examples |
| :--- | :--- | :--- |
| **Data Engineering** | `_DE`, `_data_engineer`, `_pyspark`, `_etl` | `Alex_DE_resume.pdf`, `Alex_data_engineer.pdf` |
| **Data Science / ML** | `_DS`, `_data_science`, `_ml`, `_machine_learning` | `Alex_DS_resume.pdf`, `Alex_data_science.pdf` |
| **AI / GenAI Platforms** | `_AI`, `_genai`, `_llm`, `_agent` | `Alex_AI_resume.pdf`, `Alex_genai_resume.pdf` |
| **Software Engineering** | `_SWE`, `_sde`, `_software`, `_backend`, `_fullstack` | `Alex_SWE_resume.pdf`, `Alex_backend.pdf` |
| **MLOps / DevOps** | `_MLOps`, `_devops`, `_cloud`, `_platform` | `Alex_MLOps_resume.pdf`, `Alex_devops.pdf` |

---

## 🔒 Privacy Notice
All `.pdf` files inside this directory are strictly ignored by `.gitignore` and **will never be committed or pushed to GitHub**.
