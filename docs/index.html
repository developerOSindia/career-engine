Security & Protocol Advisory Automate Responsibly — Prevent Platform Flagging

Automated applying can breach LinkedIn and Naukri terms of service and get accounts restricted. CareerEngine runs through your authentic local Chrome via CDP with humanized delay jitter (3–12s), but you should always test with --preview mode first to verify field autofill accuracy, and keep batch sizes conservative (5–15 jobs).

Deterministic 4-Stage Autonomous Pipeline

How CareerEngine bridges your authenticated Chrome browser, semantic AI models, and local disk database without third-party cloud servers.

STAGE 01
🌐

Local Chrome CDP

Attaches to your genuine Google Chrome instance via DevTools Protocol (port 9222). Inherits all active cookies, sessions, and 2FA logins without launching detectable headless binaries.

Port 9222 • Zero Headless Flags
STAGE 02
📄

Resume Selector

Parses job descriptions in real-time and dynamically selects the best-matching resume PDF from your resumes/ directory based on role tags (_DE, _DS, _AI, _SWE, _MLOps).

5 Role Tags • Dynamic Matching
STAGE 03
🧠

Screening Evaluator

Sends only isolated screening questions to rotational Gemini API keys. Answers work authorizations, experience questions, and notice periods using your configured facts with zero memory retention.

Gemini 2.5 / Flash • Rotational Keys
STAGE 04
💾

Local SQLite Store

Records each application in jobs.db on your machine with SHA-256 deduplication, platform job IDs, salary notes, and timestamps for tracking and CSV export.

CLI IMPLEMENTATION

Setup CareerEngine in Under 3 Minutes

Clone the open-source repository, configure your candidate profile facts, and launch in zero-risk preview mode.

bash — career-engine — git:(main) 
# 1. Clone the repository
$ git clone https://github.com/developerOSindia/career-engine.git
$ cd career-engine

# 2. Create Python virtual environment (Python 3.10+)
$ python3 -m venv .venv
$ source .venv/bin/activate  # On Windows: .venv\Scripts\activate
$ pip install -r requirements.txt

# 3. Launch interactive configuration wizard
$ python setup_agent.py

# 4. Start Google Chrome with remote debugging on port 9222
$ google-chrome --remote-debugging-port=9222 --user-data-dir="~/.chrome-debug"

# 5. Run in zero-risk preview mode first!
$ python main.py --mode=preview --target=linkedin --role=_DE

        FREQUENTLY ASKED QUESTIONS
        
Clarifications & Operations FAQ

        

          Honest architecture and policy details for engineers deploying CareerEngine.
        

      


      

        
        

          

            Does CareerOS apply to jobs for me?
            ▼
          

          

            No. CareerOS is a web platform for tracking job applications, interview stages, and comparing compensation in ₹ lakhs. CareerEngine is the separate, open-source companion tool that runs on your local machine to apply through your authentic Google Chrome browser.
          

        


        
        

          

            Does CareerEngine automatically sync with CareerOS?
            ▼
          

          

            No. CareerEngine is a standalone local tool that stores your application history in a sandboxed SQLite database (jobs.db) on your computer. It does not automatically sync telemetry with CareerOS web yet to preserve air-gapped security and data sovereignty.
          

        


        
        

          

            What are the account risks with automated applying?
            ▼
          

          

            Automated applying can breach LinkedIn and Naukri terms of service and risks account restriction. CareerEngine minimizes detection by using authentic Chrome DevTools Protocol (CDP port 9222) and humanized randomized delay jitter (3–12s). However, we strongly recommend running with --preview mode first and keeping batches conservative (5–15 jobs per session).
          

        


        
        

          

            Does any candidate personal data go to the cloud?
            ▼
          

          

            Your candidate profile, resumes, API keys, and SQLite database stay strictly on your local machine. Only the raw questionnaire text prompts of job screening questions are sent to the Google Gemini keys you supply in your .env file.
          

        


        
        

          

            What is the current status of Naukri support?
            ▼
          

          

            LinkedIn Easy Apply is fully operational. Naukri Quick Apply scaffolds and form evaluation structures are implemented in platforms/naukri/, and we recommend running in preview mode to verify questionnaire matching against your candidate profile.
