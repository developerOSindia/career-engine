Getting Started

Setup CareerEngine in 4 Simple Steps

Follow this quick installation workflow to set up your environment, configure your profile, and launch your first batch.

01

Clone Repository & Install Dependencies

Clone the open-source repository and install Python requirements (compatible with Python 3.10+):

Bash 
git clone https://github.com/developerOSindia/career-engine.git
cd career-engine
pip install -r requirements.txt
02

Run the Interactive Setup Agent

CareerEngine includes an intelligent CLI agent that asks for your contact details, target titles, compensation, notice period, and Gemini API keys, writing local gitignored configuration safely:

Bash 
python3 main.py setup
# Or execute directly:
python3 setup_agent.py
03

Drop Resume PDFs into resumes/

Place your resume PDFs in the resumes/ directory. Tag them by role so CareerEngine automatically attaches the most relevant version:

Bash 
# Examples:
resumes/Alex_DE_resume.pdf       # Matched for Data Engineering roles
resumes/Alex_DS_resume.pdf       # Matched for Data Science & ML roles
resumes/Alex_AI_resume.pdf       # Matched for GenAI & LLM Platform roles
resumes/Alex_SWE_resume.pdf      # Matched for Backend & Software roles
04

Launch Google Chrome in Remote Debugging Mode

Start Chrome with port 9222 enabled. Log into LinkedIn or Naukri once; your session cookies stay saved in your local directory across runs:

Bash 
./scripts/launch_chrome.sh

Common Inquiries

Frequently Asked Questions

Key architectural facts, safety considerations, and usage guidelines.

What is CareerEngine and how is it different from traditional job bots?

CareerEngine is an autonomous career operating system designed by developerOS. Traditional job bots rely on headless browsers like Selenium or Puppeteer that are instantly flagged by Cloudflare, Kasada, or LinkedIn anti-bot systems. CareerEngine controls your authentic local Google Chrome browser via Chrome DevTools Protocol (CDP port 9222), inheriting your genuine 2FA session, active cookies, and human typing cadence without triggering CAPTCHAs.

How does CareerEngine solve complex job screening questionnaires?

CareerEngine uses a multi-LLM rotational architecture. It cycles between Google Gemini 3.5 Flash-lite and Gemini 3.1 Flash-lite across multiple free API keys, with automatic DeepSeek V4 fallback. Every question answered is cached in a local permanent QA memory (profile_config.json), ensuring repeating questions are resolved in under 100ms with zero extra API consumption.

How does the Multi-Role Resume Selector determine which PDF to attach?

When parsing a job posting, CareerEngine evaluates the position title and description against target keyword clusters. It selects matching PDFs from your local resumes/ folder using semantic role tags: _DE for Data Engineering, _DS for Data Science/Machine Learning, _AI for LLM/GenAI platforms, _SWE for Backend Software Engineering, and _MLOps for Cloud DevOps roles.

Is any candidate data, resume, or API key sent to third-party servers?

No. CareerEngine adheres to a strict 100% local privacy architecture with zero telemetry. Candidate master profiles, contact credentials, SQLite database records (jobs.db), and resume PDFs never leave your machine. A pre-push git hook (.git/hooks/pre-push) actively blocks accidental pushes of personal branches or credentials to GitHub.

Can CareerEngine handle recruiter InMails and messaging?

Yes. With python3 main.py inmail --preview or --send, CareerEngine scans unread LinkedIn messaging threads, reads recruiter inquiries, and drafts personalized, professional responses highlighting candidate strengths, confirmed notice period (e.g. 30 days), and aligned compensation expectations.

Security Guarantee

Built for Open-Source Safety

Designed from day one to ensure you never accidentally expose your personal resumes, cookies, or API keys.

🔐 Git-Ignored Secret Isolation

Your API keys in .env, candidate details in profile_config.json, local database in jobs.db, and resume PDFs are strictly ignored by git.

🛡️ Pre-Push Security Guard

CareerEngine includes a pre-push git hook (.git/hooks/pre-push) that blocks pushes on designated personal branches, guaranteeing your private experiments stay local.

⚡ Rotational API Quota Protection

Smart round-robin rotation across free Google AI Studio keys prevents rate limiting (HTTP 429) while keeping zero runtime cost for users.
