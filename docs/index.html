Chrome CDP Integration

Controls your real Google Chrome profile over remote port 9222. Inherits your active cookies and 2FA credentials without launching detectable headless browsers.

🧠

Rotational Gemini AI

Cycles between Google Gemini 3.5 Flash-lite and 3.1 Flash-lite keys with DeepSeek fallback to evaluate complex questionnaire forms accurately.

📄

Multi-Role Resume Selector

Matches and uploads the most relevant resume PDF from resumes/ based on job requirements (_DE, _DS, _AI, _SWE, _MLOps).

💬

Recruiter InMail Auto-Reply

Inspects unread LinkedIn messages, analyzes recruiter pitches, and drafts concise replies with your notice period and salary expectations.

🔒

Local-First Storage

Your profile facts, resumes, API keys, and SQLite database stay on your machine. Only the raw questionnaire prompts are sent to Gemini.

Getting Started

Setup CareerEngine in 4 Steps

Install dependencies, configure your local candidate profile, and launch Chrome.

01

Clone Repository & Install Dependencies

Clone the open-source repository and install Python requirements (compatible with Python 3.10+):

BASH 
git clone https://github.com/developerOSindia/career-engine.git
cd career-engine
pip install -r requirements.txt
02

Run the Interactive Setup Agent

CareerEngine includes an onboarding wizard that asks for your contact details, compensation expectations, notice period, and Gemini API keys:

BASH 
python3 main.py setup
# Or execute directly:
python3 setup_agent.py
03

Drop Resume PDFs into resumes/

Place your resume PDFs in the resumes/ folder with role tags so CareerEngine attaches the most relevant version:

BASH 
# Examples:
resumes/Alex_DE_resume.pdf       # Matched for Data Engineering roles
resumes/Alex_DS_resume.pdf       # Matched for Data Science & ML roles
resumes/Alex_AI_resume.pdf       # Matched for GenAI & LLM Platform roles
resumes/Alex_SWE_resume.pdf      # Matched for Backend & Software roles
resumes/Alex_MLOps_resume.pdf    # Matched for DevOps & Cloud roles
04

Launch Chrome in Remote Debugging Mode

Start your Google Chrome browser with port 9222 enabled. Log into LinkedIn and Naukri once; your sessions remain stored in your local directory:

BASH 
./scripts/launch_chrome.sh

Common Inquiries

Frequently Asked Questions

Key architectural facts, account safety, and developerOS integration.

What is CareerEngine and how does it relate to CareerOS?

CareerOS is the web platform where engineers track and compare applications, interviews, and offers in ₹ lakhs. CareerEngine is the open-source automation companion: it runs locally on your machine, attaches to your Google Chrome browser via CDP, and assists with filling job applications. CareerEngine does not automatically sync with CareerOS yet.

Is there account risk when using CareerEngine?

Yes. Automating applications can breach the terms of service on platforms like LinkedIn and Naukri, and carries the risk of account restriction. CareerEngine controls your genuine Chrome browser with organic dwell times and typing jitter to minimize detection, but you should always run with --preview / --dry-run first, inspect applications, and avoid applying in aggressive volumes.

Is candidate data sent to the cloud?

Your candidate profile, resumes, API keys, and local SQLite database (jobs.db) remain stored solely on your machine. When completing applications, only the specific screening questionnaire prompts are sent to the Google Gemini API keys that you provide.

How does the Multi-Role Resume Selector work?

CareerEngine evaluates position titles and descriptions against predefined keyword clusters, matching files in your local resumes/ folder with role tags (_DE for Data Engineering, _DS for Data Science, _AI for GenAI/LLM, _SWE for Backend, _MLOps for Cloud DevOps).

How do I prevent accidentally pushing my personal data to GitHub?

CareerEngine includes a git pre-push security guard (.git/hooks/pre-push) and comprehensive .gitignore rules. Private credentials (.env), custom facts (profile_config.json), resume PDFs, and databases (jobs.db) are strictly excluded from git tracking.
