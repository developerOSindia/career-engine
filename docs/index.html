Getting Started

Setup CareerOS in 4 Simple Steps

Follow this quick installation workflow to set up your environment, configure your profile, and launch your first batch.

01

Clone Repository & Install Dependencies

Clone the open-source repository and install Python requirements (compatible with Python 3.10+):

Bash 
git clone https://github.com/developerOSindia/careeros.git
cd careeros
pip install -r requirements.txt
02

Run the Interactive Setup Agent

CareerOS includes an intelligent CLI agent that asks for your contact details, target titles, compensation, notice period, and Gemini API keys, writing local gitignored configuration safely:

Bash 
python3 main.py setup
# Or execute directly:
python3 setup_agent.py
03

Drop Resume PDFs into resumes/

Place your resume PDFs in the resumes/ directory. Tag them by role so CareerOS automatically attaches the most relevant version:

Bash 
# Examples:
resumes/Alex_DE_resume.pdf       # Matched for Data Engineering roles
resumes/Alex_DS_resume.pdf       # Matched for Data Science & ML roles
resumes/Alex_AI_resume.pdf       # Matched for GenAI & LLM Platform roles
resumes/Alex_SWE_resume.pdf      # Matched for Backend & Software roles
04

Launch Google Chrome in Remote Debugging Mode

Start Chrome with port 9222 enabled. Log into LinkedIn or Naukri once; your session cookies stay saved in your local directory across runs:

Bash 
./scripts/launch_chrome.sh

LinkedIn Easy Apply Commands

Live & Dry-Run

Autonomously scan Easy Apply jobs, handle multi-page modals, answer questions via Gemini, and attach role-specific resumes.

Security Guarantee

Built for Open-Source Safety

Designed from day one to ensure you never accidentally expose your personal resumes, cookies, or API keys.

🔐 Git-Ignored Secret Isolation

Your API keys in .env, candidate details in profile_config.json, local database in jobs.db, and resume PDFs are strictly ignored by git.

🛡️ Pre-Push Security Guard

CareerOS includes a pre-push git hook (.git/hooks/pre-push) that blocks pushes on designated personal branches, guaranteeing your private experiments stay local.

⚡ Rotational API Quota Protection

Smart round-robin rotation across free Google AI Studio keys prevents rate limiting (HTTP 429) while keeping zero runtime cost for users.
